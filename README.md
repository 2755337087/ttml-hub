# LunaBeat TTML 歌词站

LunaBeat TTML 歌词站是一个面向 LunaBeat 及其他播放器的开放歌词目录，收集并制作逐字 TTML 歌词供下载，支持按歌曲名称、艺术家、专辑或流媒体 ID 搜索。

[搜索并下载 TTML 歌词](https://2755337087.github.io/ttml-hub/)

[提交歌词](https://github.com/2755337087/ttml-hub/issues/new?template=lyric-request.yml)

[TTML 歌词格式说明](docs/TTML歌词格式规范.md)


[求歌词](https://github.com/2755337087/ttml-hub/issues/new?template=lyric-wish.yml)


[反馈歌词错误](https://github.com/2755337087/ttml-hub/issues/new?template=lyric-feedback.yml)
